Migration

Nexus-ready shape

The clean export keeps source IDs and history while introducing a canonical player key. A later Nexus migration can attach a nexusPlayerId without rewriting old tournament records.

  • players: canonical identity + source IDs
  • events: one record per weekly tournament
  • results: event, player, placement, points
  • source: hotdogshop-v29 retained for lineage

Safety

What this version deliberately avoids

No player merges are written back to Firestore. No historical document is deleted. No V29 code path is modified. Cleanup should only be applied after the raw Firebase export has been downloaded and duplicate groups have been reviewed.
